## Purpose

Provides local persistence for all weather data, chat sessions, app settings, and weather station data using SQLDelight with platform-specific SQLite drivers.

---

## Responsibilities

- Defining the `Database` interface abstracting all SQLDelight query operations.
- Implementing `SqlDelightDatabase` which wraps `AppDatabase` (generated by SQLDelight).
- Mapping between API/domain models (`WeatherResponse`, `Day`, `Hour`, `Station`) and SQLDelight DB rows via `DataMapping`.
- Upsert semantics for weather data: new places get full insert; existing places get only new days added (existing days never overwritten).
- Transactional station upsert: delete-then-insert in a single transaction (`upsertStations`).
- Chat session and message persistence (`ChatRepository` / `ChatRepositoryImpl`).
- App settings key-value store (`AppSettingsRepository` using `appDatabaseQueries.getAppSetting` / `setAppSetting`).
- Platform-specific `DatabaseDriverFactory` (expect/actual) for Android (Room-like SQLite) and iOS (native sqlite3 via CocoaPods).
- Database export/import for backup (expect/actual `DatabaseExportImport`).

## Dependencies

### Internal
- `com.km.rewinds.db.AppDatabase` — SQLDelight generated database class.
- `core.DataMapping` — model translation.
- `core.DbAdapters` — custom column adapters (e.g. `listOfStringAdapter` for `preciptype` columns).

### External
- **SQLDelight** — compile-time query generation, type-safe queries.
- **sqlite3** (iOS, via CocoaPods) — native C library bridged through Kotlin/Native C interop.

## Known constraints

- `getSavedPlaceFull` loads all days and all hours for a place in a single call. For places with large datasets this is a heavyweight operation; the session cache in `WeatherRepositoryImpl` is the primary mitigation.
- `getPlaceDayCounts` uses a GROUP BY query and returns only the count — it does not load day rows. This is the only query used on the Home screen to avoid the full-load cost.
- `cleanupForecastDays` is implemented but currently disabled (commented out in `HomeViewModel`). Days with `datetime > yesterday` may be present in the database.
- SQLDelight schema file location: `composeApp/src/commonMain/sqldelight/`.
- Database filename: `app.db` (`AppConstants.DATABASE_NAME`).
- `preciptype` is stored as `List<String>` using a custom `listOfStringAdapter` in `DbAdapters`.

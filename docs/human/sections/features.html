Features

A tour of what each screen does and how the modules fit together.

Home — Places list

The opening screen of the Places tab shows all saved locations. For each place the app displays how many weather days are stored, so you can see at a glance which locations have rich history. Loading this list is intentionally lightweight — only day counts are queried, never the full weather records — so it stays fast even with many places and years of data.

From the Home screen you can:

  • Search for a new location using free-text (powered by Open-Meteo geocoding).
  • Add a location from the search results. Station metadata is fetched immediately; weather days are downloaded later on demand.
  • Delete a saved place (with a confirmation dialog).
  • See a banner if your Visual Crossing API key is missing or invalid, with a direct link to Settings.
  • Access a debug panel for database export and import (hidden by default).
The app re-checks your API key status each time you return to the Home tab, so the nudge banner disappears as soon as you save a valid key in Settings.

Place Summary — year/month grid

Tapping a place opens its summary screen. This shows a compact grid of months, colour-coded to indicate how much data is stored:

  • Full — the month has a complete (or near-complete) set of daily records.
  • Partial — some days are present but the month is not complete.
  • No data — nothing stored yet for that month.

You can tap any month cell to open the Monthly Statistics drill-down, or tap a download button to fetch a full month from Visual Crossing. Average monthly temperatures are shown alongside the year selector so you can quickly spot seasonal patterns.

The screen also shows a map of nearby weather stations. Station data is fetched automatically on first visit (silently in the background); you can also refresh it manually.

Monthly Statistics — daily detail

The monthly statistics screen shows every stored day in the selected month as a card, with temperature, precipitation, wind speed, and a sunrise/sunset time. A wind bar chart at the top highlights the day with the strongest sustained wind.

The screen computes aggregated statistics for the month:

  • Temperature extremes (absolute min, absolute max, daily averages).
  • Total rainfall and total solar energy.
  • Average sustained wind speed.
  • A count of days that match your current days-of-interest filter.

You can navigate forward and back between months without leaving the screen. Missing months can be downloaded directly from here as well.

The days-of-interest filter is configured in Settings. The default filter highlights days with sustained wind above 20 km/h for at least 2 hours and temperature at or above 10°C — a reasonable threshold for kite/windsurf sessions.

AI Chat — weather assistant

The Chat tab gives you a conversational interface to your stored weather data, powered by Claude (claude-haiku-4-5). You can ask natural-language questions about any of your saved places.

Example questions the assistant can answer:

  • "How many days had wind above 25 knots in Tarifa last summer?"
  • "What were the best kitesurfing days in Maui in January 2024?"
  • "Compare average wind speeds between my two favourite spots."
  • "What's the typical temperature range in Dakhla in October?"

If the data for a question hasn't been downloaded yet, the assistant asks for your confirmation before making any API call to Visual Crossing — you stay in control of when data is fetched.

Chat history is persisted per session in the local database, so your conversations survive app restarts.

See the AI Chat deep-dive for technical details on tools, the permission gate, and API key setup.

Settings

The Settings tab is where you configure the two API keys the app needs:

  • Anthropic API key — required for AI chat. On iOS this is stored securely in the Keychain and persists across app restarts. On Android it comes from the build configuration.
  • Visual Crossing API key — required for downloading weather data. On iOS this is stored in the Keychain; on Android it is set at build time.

Settings also lets you define your days-of-interest filter in plain language. You describe the conditions you care about ("good kitesurfing days: wind above 20 knots, no rain, temperature above 15°C") and the app uses Claude to parse that description into a structured filter. The resulting filter is then applied in Monthly Statistics to highlight matching days.

Parsing the days-of-interest criteria uses your Anthropic API key. Each save of the filter makes one AI call.

UI Theme

ReWinds uses a single dark-only Midnight Blue design system. There is no light mode. The colour palette is defined in ReWindsColors and mapped to Material 3 semantic slots.

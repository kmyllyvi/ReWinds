Manual Test Checklist

The async QA backlog. PRs no longer wait for a manual pass — once Marcy approves and CI is green, they merge. Any manual verification that a reviewer agent can't perform is logged here as a test case and checked off later, on device.

How this works
  • Randy appends a row for every merged PR that has behaviour needing a human eye (device/simulator run, visual/UX check) — one row per distinct check.
  • You verify on device whenever you like, in batches. To mark a case done, add checked to its checkbox and add class="done" to its <tr>, then commit. State is git-tracked, so verification status is shared and auditable.
  • Automate column — if the reviewer thinks the case should become an automated test (Compose/Maestro/unit), it's flagged here. File a ticket for it, then you can delete the row once the automated test lands.
  • Remove rows once verified and either automated or no longer relevant. This is a working backlog, not a permanent archive.

ReWinds

A Compose Multiplatform app for wind-sports enthusiasts — historical weather data, saved locations, and AI-powered condition analysis.

What is ReWinds?

ReWinds is an iOS and Android application built on Kotlin Multiplatform with Compose for the UI. It lets kite- and windsurfers save their favourite spots, accumulate years of historical weather data from the Visual Crossing API, and interrogate that data via an AI chat assistant backed by Claude.

The codebase shares the vast majority of logic between platforms through commonMain, with thin platform bridges in iosMain / androidMain for things like secure storage and native driver initialisation.
